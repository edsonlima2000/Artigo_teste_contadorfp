# Contributing / Como contribuir

Thank you for your interest. Issues and pull requests may be written in English or Portuguese.

## Before opening an issue

- Search existing issues.
- Do not include passwords, API keys, tokens, personal data, or private datasets.
- For bugs, include the operating system, runtime version, exact steps, expected behavior, and relevant logs.
- For feature requests, explain the use case and keep the proposal within the project's current scope.

## Pull requests

1. Fork the repository and create a focused branch.
2. Keep changes small and document user-visible behavior.
3. Add or update tests when behavior changes.
4. Run the documented checks locally.
5. Confirm that you have the right to contribute every file and that no secret or restricted material is included.

By submitting a contribution, you agree that your contribution may be distributed under the repository's MIT License. Third-party material remains under its original terms.
